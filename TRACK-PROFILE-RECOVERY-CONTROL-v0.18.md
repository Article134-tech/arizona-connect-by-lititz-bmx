# Arizona Connect v0.18 — Track Profile Recovery Control

**Scope:** Chandler BMX (`AZ-TRK-0001`) only.

This checkpoint applies the approved Arizona BMX Atlas visual language to one representative track profile before any pattern is propagated across all 25 governed track records.

## Locked upstream surfaces
- Arizona Connect v0.16 launcher: unchanged.
- Arizona BMX Atlas home / v0.17 files: unchanged.
- Research Register, data JSON/CSV, Timeline, Relationships, Events, Media, Recovery and Methodology: unchanged.

## Profile pattern
The Chandler profile must visibly preserve:
1. track identity and present evidence state;
2. registered geospatial state and coordinates;
3. current-record boundary;
4. explicit open lineage to Chandler Jaycees BMX;
5. track → claim → source → evidence-boundary drilldown;
6. media-rights treatment;
7. connected Timeline / Relationships / Events routes;
8. correction pathway.

## Evidence discipline
No lineage arrow is asserted between Chandler BMX and Chandler Jaycees BMX. The period and current identities remain separately governed until continuity is proved.

This is a pattern candidate, not authorization to restyle all track profiles without owner visual approval.
