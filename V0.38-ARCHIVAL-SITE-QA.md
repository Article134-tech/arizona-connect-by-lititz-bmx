## Browser runtime gate — environment blocker

A 36-navigation desktop/mobile harness was attempted against both `file://` routes and a local HTTP server. Every navigation was intercepted before the product loaded with:

`net::ERR_BLOCKED_BY_ADMINISTRATOR`

The installed Chromium is governed by the host's managed policy containing a mandatory `URLBlocklist` of `*`. The resulting browser page states that the organization does not allow the local URL. This is not evidence of an Arizona Connect runtime failure, but it means the required runtime/visual gate cannot be claimed as passed.

The managed browser policy was **not altered, removed or bypassed**.
