# Arizona Connect v0.21 — Timeline Recovery Control

Date: 2026-08-20

## Governing direction

The Timeline now inherits the approved Arizona BMX Atlas product family rather than behaving like a separate generic subpage.

## Locked evidence rules

- Timeline data remains the governed `arizona-history-timeline-v1.1.json` set.
- 33 published milestones remain published.
- 5 open lineage questions remain optional and off by default.
- Date precision remains visible and is never silently normalized for display.
- Timeline → claim / track / event drilldown remains explicit.
- Geographic context uses only the v0.20 Arizona-only absolute map asset.
- Timeline markers are created only from governed A4 registered track coordinates.
- Linked tracks without defensible coordinates remain unpinned.
- Current, site-approximate and exact-historical points retain distinct map treatments.

## Preservation boundary

This checkpoint changes only the Timeline presentation layer plus its Timeline-specific CSS/JS and documentation. It does not change the approved Arizona Connect launcher, Atlas home, track profiles, Research Register, timeline data, track census, A4 location register, relationships, events, media, or recovery data.
