PUBLIC ARIZONA CLAIM · Historical Tracks / Period Directory

AZ-PUB-0055

A BMX track guide last modified in 1998 listed Thunder Raceway in Show Low, Arizona as an ABA BMX track and named Chris Tippie as the contact.

Evidence typeFACT — CONTEMPORANEOUS PERIOD WEB DIRECTORY LISTING
Source classB1
ConfidenceHIGH FOR BMX DIRECTORY LISTING

LIMITS OF THE EVIDENCE

This proves a 1998 BMX-directory listing named Thunder Raceway in Show Low. It must not be silently conflated with the present-day Deuce of Clubs Thunder Raceway motor-racing facility without location/identity evidence.
