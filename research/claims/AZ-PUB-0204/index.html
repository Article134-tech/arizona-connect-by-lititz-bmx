PUBLIC ARIZONA CLAIM · Historical Tracks / Period Directory

AZ-PUB-0204

The November 1991 GO: The Rider’s Manual directory lists “Navajo County BMXPRESS” in Holbrook with Paul DoBell and telephone number 602-524-6407; a separate “NEW TRACKS” box in the same issue lists Holbrook, Arizona / BMX Press / Paul Dobell with the same number.

Evidence typeFACT — PERIOD BMX PUBLICATION / DIRECTORY
Source classB1
ConfidenceHIGH FOR NOVEMBER 1991 PUBLISHED BMXPRESS IDENTITY + CONTACT

LIMITS OF THE EVIDENCE

This independently preserves the BMXPRESS identity, Holbrook locality, Paul DoBell/Dobell contact and telephone number in a national BMX publication. The “NEW TRACKS” directory label is not treated as proof that the physical Holbrook facility first opened in 1991; period local newspaper evidence documents the fairgrounds BMX facility in 1989.
