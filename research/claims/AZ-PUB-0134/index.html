PUBLIC ARIZONA CLAIM · Historical Tracks / Period Directory Identity

AZ-PUB-0134

The May 1985 BMX Action Arizona track directory separately lists Window Rock BMX Indoor and Window Rock BMX in Window Rock, with Jerry Pete and the same published telephone number on both entries.

Evidence typeFACT — PERIOD BMX PUBLICATION / DIRECTORY
Source classB1
ConfidenceHIGH FOR MAY 1985 SEPARATE PRINTED IDENTITIES / DIRECT PAGE VERIFIED

LIMITS OF THE EVIDENCE

This moves the earliest directly recovered Window Rock BMX Indoor directory occurrence from June back to May 1985 and strengthens a shared-contact signal. It does not establish whether the two printed identities were separate facilities, an indoor/outdoor variant, a rename, the same organization, or the same physical course.
