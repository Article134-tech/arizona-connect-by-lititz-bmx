PUBLIC ARIZONA CLAIM · Historical Tracks / Geographic Registration

AZ-PUB-0146

The Town of Chino Valley identifies current Memory Park at Palomino Road and N Road 1 West; combined with USA BMX’s repeated 2002–2003 event address and its embedded 2003 driving-directions coordinate, the evidence supports an approximate Memory Park property-level location for Mile High BMX (Chino Valley).

Evidence typeSYNTHESIS — OFFICIAL SANCTIONING-BODY EVENT ADDRESS + MUNICIPAL PARK CROSS-CHECK
Source classA1
ConfidenceHIGH FOR MEMORY PARK ADDRESS ASSOCIATION; MEDIUM-HIGH FOR EVENT-SITE PROPERTY; LOW FOR COURSE CENTER

LIMITS OF THE EVIDENCE

The marker represents the published 2002–2003 event-address / current Memory Park property association, not an exact historical dirt-course center. It does not merge Mile High BMX (Chino Valley) with 1983–1984 Mile-Hi BMX, the 1984 Chino Valley BMX directory identity, or the later BMX facility documented at Old Home Manor.
