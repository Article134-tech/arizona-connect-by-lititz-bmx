PUBLIC ARIZONA CLAIM · Historical Tracks / Period Directory Continuity

AZ-PUB-0135

The May 1985 BMX Action directory lists Hills ’n Spills BMX in Peoria with Gene Garcez; the June 1985 BMX Plus! directory repeats the same identity, contact and published telephone number.

Evidence typeFACT — PERIOD BMX PUBLICATION / DIRECTORY COMPARISON
Source classB1
ConfidenceHIGH FOR REPEATED MAY–JUNE 1985 DIRECTORY IDENTITY / DIRECT PAGE VERIFIED

LIMITS OF THE EVIDENCE

This moves the earliest directly recovered Hills ’n Spills BMX directory occurrence from June back to May 1985 and proves consecutive recovered directory continuity for that printed identity. It does not prove a formal rename from Peoria Dunes BMX, an identical physical course, uninterrupted operation, ownership or organizational succession.
