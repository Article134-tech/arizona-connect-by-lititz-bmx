EXPANSION CONTROL

The first 50 are frozen so growth cannot rewrite the starting line.

Expansion records must clear the same claim → evidence → source → boundary rule. A period directory can prove that a track was listed; it cannot automatically prove exact dates, location, lineage or uninterrupted operation.

Baseline A

AZ-PUB-0001 through AZ-PUB-0050 remain the frozen First Edition control set.

Governed growth through v0.55

Claims 51–172 are additive growth records. They do not silently revise the frozen first 50, and every later claim retains its own source and evidence boundary.

Period directories

Contemporaneous directories can strongly establish a period listing. Public wording stays about the listing unless independent evidence supports more.

Official records

Municipal leases, official USA BMX event listings and sanctioning-body results can support stronger occurrence or operation claims.

Same-name conflict

Thunder Raceway's BMX-directory occurrence is kept separate from the modern motor-racing facility with a similar name.

Correction remains open

New period documents may strengthen, narrow or contradict these records. Changes remain explicit and versioned.

Historical naming on current live web pages

A current page shell can inherit a present-day track or organization label around older event content. The current page shell is present-interface evidence, not automatically historical-name evidence.

Historical naming is dated from event-specific text, period results, archived versions, dated announcements, municipal records, or equivalent contemporaneous evidence.

Control example: the September 27, 2020 USA BMX event page currently labels the track Interstate BMX while the event description itself names High Desert 66. Inspect USA BMX event 445128 ↗
