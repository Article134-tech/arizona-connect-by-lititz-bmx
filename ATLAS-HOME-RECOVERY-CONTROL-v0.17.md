# Arizona Connect v0.17 — Atlas Home Recovery Control

Date: 2026-08-20

## Governing decision

The Arizona Connect launcher approved at v0.16 remains locked and unchanged.

This checkpoint changes only the **Arizona BMX Atlas home interface**. It deliberately reuses the established Lititz BMX Global BMX Research Atlas product pattern rather than inventing another state-dashboard design.

## Visual / interaction source

Established Global Atlas pattern:

- Lititz BMX header and compact release ribbon;
- geographic discovery hero;
- map / alternate-access controls;
- short evidence-orientation strip;
- inspectable metrics;
- searchable profile explorer;
- explicit evidence-status distinctions;
- correction pathway;
- machine-readable endpoints.

## Arizona-specific substitutions

- world geography → Arizona governed track geography;
- country/profile → track/profile;
- global profile counts → Arizona track / claim / timeline / relationship counts;
- globe / flat map / list → current map / historical layer / accessible list;
- global evidence lanes → current / historical / open-lineage / recovery states;
- existing Arizona Timeline, Relationships, Events, Media, Recovery and Research Register remain the governing child layers.

## Frozen content / data

No Arizona research records were edited in this checkpoint.
No track identities were merged.
No new coordinates were invented.
No recovery lead was promoted.

The existing `data/`, track profile pages, Timeline, Relationships, Events, Media, Recovery, Methodology and Research Register payload remains unchanged.
