# Arizona Connect v0.33 — Track-by-Track Recovery Control

## Governing decision

Deepen the newly expanded historical census track-by-track. Preserve role boundaries: a directory contact is not automatically an owner/operator; an attributed rider memory remains personal truth; a park reference is not an exact historical track-center.
