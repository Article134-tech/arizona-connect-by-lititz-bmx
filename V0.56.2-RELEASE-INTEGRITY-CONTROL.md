# Arizona Connect v0.56.2 — Release Integrity Correction Control

## Release posture

v0.56.2 is a correction-only release on top of deployed v0.56.1. It adds no research admissions, no new track identities, no new Timeline records, no new events, no new source IDs, and no new map coordinates.

## Canonical corpus retained

- 173 public Arizona claims
- 33 supporting evidence records
- 135 source IDs used by published public/supporting records
- 43 tracks — 11 current / 32 historical
- 83 Timeline milestones + 4 open questions
- 30 events
- 17 relationships
- 19 media routes
- 18 mapped / 25 intentionally unpinned

## Corrections required by hosted review

- Every public claim title directly links to its claim page.
- Every public claim ID directly links to its claim page.
- Whole-card claim navigation remains available.
- Supporting Evidence fragment links resolve to the exact supporting record.
- Track recovery links open the matching track recovery record rather than the generic Recovery page.
- Unpinned track profiles return to a Track Explorer view focused on that track rather than implying a map pin exists.
- Atlas map controls provide **All / Current / Historical**, with **All** selected by default.
- Canonical counts are regenerated from current datasets and checked against public surfaces.
- Timeline static records match the complete current Timeline dataset.
- Source Directory IDs, Categories, Events, Tracks, Claims, Timeline and Recovery DOM records are checked against canonical data.
- Visitor-facing developer/research-system narration is removed from public surfaces, including internal location-state enums and “how the system works” wording.

## Frozen UX rule

The v0.55.8 frozen interaction/style baseline remains the product baseline. v0.56.2 records explicit authorized correction hashes only for interaction assets changed to repair the defects above. Future content growth must continue to pass the frozen-UX guard.

## Geographic boundary

No coordinate, map boundary, mapped/unpinned decision, or Geographic Absolute point is changed by v0.56.2. The public wording around location confidence is simplified without changing the underlying location evidence state.
