# Arizona BMX History Timeline — v1 Control

**Checkpoint:** Arizona Connect v0.13  
**Date:** 2026-08-20  
**Published milestones:** 28  
**Optional open questions:** 5  
**Governed event records:** 11  
**Current chronological span:** 1977–2026

## Architecture

Timeline milestone → Research Register claim(s) → Atlas track(s) → Event record(s) → artifact/media/source routes.

The timeline is a presentation layer over governed evidence. It is not a second historical database.

## Date precision

Permitted timeline date states:
- exact day;
- exact range;
- month;
- year;
- range;
- circa/retrospective;
- directory snapshot;
- OPEN.

The interface must not manufacture an exact date merely to place an item more neatly.

## Open-question layer

The following appear only when the user enables the unresolved layer:
- Chandler Jaycees BMX ↔ current Chandler BMX;
- Road Runner BMX ↔ Black Mountain exact chronology/site continuity;
- London Bridge / Sara Park ↔ current Lake Havasu City BMX;
- historical Tucson tracks ↔ Sports Park / Tucson BMX;
- High Desert 66 BMX ↔ Interstate BMX.

These are research questions, not timeline facts.

## Event normalization

The initial Phase 5 event register contains 11 records. One event/series occurrence is one event record. Rider finishes, awards and artifacts relate to that event rather than duplicating it.
