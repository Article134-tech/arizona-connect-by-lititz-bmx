READ THE GAPS TOO

An honest timeline includes uncertainty.

Four lineage questions remain optional and visually separate. They exist because the historical record is incomplete, not because the Atlas needs filler.

Milestone

A dated occurrence supported at the level stated by its claim, source or event record.

Date precision

The date state shown in the governed record. It is never silently normalized to January 1 for display.

Open question

A chronology problem kept visible for research, but excluded from the default settled timeline.

Geographic absolute

Only governed track coordinates can create map markers. Unpinned track records remain unpinned.
