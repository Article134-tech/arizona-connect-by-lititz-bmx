HISTORICAL TRACK PROFILE · Chino Valley, ARIZONA

Mile High BMX (Chino Valley)

USA BMX records State Qualifiers at Mile High BMX in Chino Valley on August 11, 2002 and August 10, 2003, both with 1020 W Palamino Rd as the published address. The Town currently identifies Memory Park at Palomino Road and N Road 1 West. The Atlas shows only an approximate Memory Park property location. This record remains separate from 1983–1984 Mile-Hi BMX, the 1984 Chino Valley BMX directory identity, and later Old Home Manor BMX-site evidence.
