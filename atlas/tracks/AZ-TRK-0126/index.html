AZ-PUB-0132 · B1 · HIGH FOR PUBLISHED WINDOW ROCK BMX INDOOR NAME / DIRECT PAGE VERIFIED

Historical Tracks / Period Directory Identity

The June 1985 BMX Plus! Arizona track directory prints “Window Rock, Window Rock BMX,” followed by “Window Rock BMX Indoor” and Jerry Pete’s contact line.

Boundary: The directory page establishes Window Rock BMX Indoor as a printed period identity in the Window Rock listing. It does not establish whether this was a second facility, an indoor variant of Window Rock BMX, a rename, a shared organization, or the same physical site. The identities remain separate pending stronger evidence.

AZ-PUB-0134 · B1 · HIGH FOR MAY 1985 SEPARATE PRINTED IDENTITIES / DIRECT PAGE VERIFIED

Historical Tracks / Period Directory Identity

The May 1985 BMX Action Arizona track directory separately lists Window Rock BMX Indoor and Window Rock BMX in Window Rock, with Jerry Pete and the same published telephone number on both entries.

Boundary: This moves the earliest directly recovered Window Rock BMX Indoor directory occurrence from June back to May 1985 and strengthens a shared-contact signal. It does not establish whether the two printed identities were separate facilities, an indoor/outdoor variant, a rename, the same organization, or the same physical course.
